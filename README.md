# حي على الصلاة

Hayya ‘ala-s-Salah: a free, open-source Android prayer application focused on reliable prayer times, private habit tracking and an original minimalist interface.

**Status: specification and handoff only. The Android application is not implemented yet.**

- [Approved implementation plan](docs/IMPLEMENTATION_PLAN.md)
- [Research and sources](docs/RESEARCH.md)
- [Development handoff](HANDOFF.md)

Development will run on Dukhan and GitHub CI. Real-device testing takes place locally, initially on a Samsung S23 Ultra. Build/install instructions will be added when the first runnable milestone exists.

Original application code is licensed under GPL-3.0-or-later. Third-party code, fonts, geographic data and audio retain their own licenses; those must be documented before inclusion. No accounts, ads, telemetry or runtime backend are planned for v1.
