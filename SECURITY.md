# Security reporting

Report a suspected privacy, data-loss, signing or alarm-security defect through the
repository private vulnerability reporting feature if available. Otherwise open an
issue requesting a private contact without disclosing exploit details or private data.
Do not upload prayer history, coordinates, signing secrets, imported audio or raw logs.

Include affected commit/version, Android/device build, minimal reproduction and impact.
The internal preview is not a production alarm/reliability release. No supported public
version or guaranteed response time is established yet.
